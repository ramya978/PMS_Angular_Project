A · Units of measure

The units used to count, buy and issue stock. Weight, Volume, Length and Count units are the measuring units offered next to the size on an item (500 ml, 52 g) – add any you need, for example cl, oz or m². The number next to each unit is how many items use it.

Lower case, up to 8 letters – shown on documents
A unit in use cannot be deleted, only renamed
