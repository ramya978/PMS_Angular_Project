System – what runs automatically on this screen
  • DAS-X01 · Registry sync – When a module is released its new approval types are registered here with the default escalation times.
  • DA-X01 · Approval router – Uses these times, the levels of the module and the delegation of DA-07.
  • DA-X02 · Escalation timer – Every 5 minutes moves unanswered requests to the next level after the time set here.
