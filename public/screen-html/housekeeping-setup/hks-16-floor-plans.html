Help for this screen HKS-16
What it is for
Floor layout images with the position of every room, used by the floor plan view of the room status board.
How it works
1. Press Upload on a floor and choose the image. 2. Press Place rooms and put each room tile in its position. 3. Save positions. Remove plan returns that floor to room tiles.
Opened from
Housekeeping Setup Home (HKS-01) › Sections › Floor plan
Leads to
No other screen is opened from here
Sends to
Room status board – floor plan view (HK-02-3)
Note
Static screen (HTML and CSS only): it shows the layout, fields and sample data. Saving and live data come when the backend is connected.
