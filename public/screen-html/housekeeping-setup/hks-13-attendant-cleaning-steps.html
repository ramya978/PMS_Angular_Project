Help for this screen HKS-13
What it is for
The step-by-step list an attendant sees on the phone for each kind of task – separate from the supervisor’s inspection checklist.
How it works
1. Choose a task type. 2. Press Add step, or Edit on a step. 3. Tick “Mandatory” for steps that must be done, and choose a count or photo if the phone should ask. 4. Use Re-order to change the order.
