Help for this screen HKS-07
What it is for
The cleaning tasks of every public area and how often they are done: every N hours between two times, daily at set times, or weekly on set days, with the shift and the standard minutes.
How it works
1. Press Add schedule or Edit. 2. Choose the area, write the task and pick how often it repeats. 3. Save. Use Preview day to see the tasks a date will get.
Opened from
Housekeeping Setup Home (HKS-01) › Public areas
Leads to
HKS-P07 PA Task Schedule Form, HKS-07-1 Areas, HKS-08 inspection checklists
Sends to
Public area tasks (HK-15) and the Housekeeping phone app
Note
Static screen (HTML and CSS only): it shows the layout, fields and sample data. Figures marked “calculated” are pre-computed. Saving and live data come when the backend is connected.
