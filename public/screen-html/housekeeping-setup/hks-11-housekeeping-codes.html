Help for this screen HKS-11
What it is for
The code lists used in housekeeping: status change reasons, out of order / out of service reasons, room conditions, refused-service reasons, log book categories and discrepancy outcomes.
How it works
1. Choose a list above. 2. Press Add code, or Edit on a row. 3. To stop a code being used, press Deactivate – old entries keep it.
Opened from
Housekeeping Setup Home (HKS-01) › Codes & keys
