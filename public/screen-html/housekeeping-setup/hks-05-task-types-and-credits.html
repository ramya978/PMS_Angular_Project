Help for this screen HKS-05
What it is for
The cleaning task types, the credits and standard minutes of each task for each room type, and the linen-change cycle. The allocation uses credits to share the work fairly.
How it works
1. Add or edit a task type in section A. 2. Type credits and minutes into the matrix; use Copy room type to start a new room type. 3. Check Preview workload. 4. Press Save matrix – credit changes go to the Rooms Division Manager for approval.
