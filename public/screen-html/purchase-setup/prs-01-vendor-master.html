Only Approved vendors can be chosen on RFQs, POs (PR) and vendor bills (FN). Bank changes need approval again (BR-01). MSME vendors are paid within 45 days (BR-03).

System – what runs automatically on this screen
  • PRS-X01 · GSTIN / PAN validation – On every vendor save: GSTIN 15-character format and checksum, PAN 10-character format and the PAN–GSTIN match (BR-02); optional online check on the GST portal. Unregistered vendors are flagged for reverse charge.
  • PRS-X02 · Setup audit logger – Every add, change, approval, hold and blacklist is written to the audit log with user, time, old and new values.
Vendor added – V-3044 Vembanad FloristsSaved as Pending approval; GSTIN and PAN checked (PRS-X01). Lakshmi Ishaan (Financial Controller) is notified to approve it. Written to the setup audit log with the old and new values (PRS-X02).
Vendor put on holdThe highlighted vendor cannot be used on new RFQs or POs until the hold is released. Written to the setup audit log with the old and new values (PRS-X02).
Vendor blacklistedThe highlighted vendor is no longer usable on RFQs or POs (PR). Written to the setup audit log with the old and new values (PRS-X02).
Hold releasedThe highlighted vendor is Approved again and appears on RFQs and POs. Written to the setup audit log with the old and new values (PRS-X02).
Vendor savedChanges saved on the highlighted vendor. A changed bank account sends it back to the Financial Controller (BR-01). Written to the setup audit log with the old and new values (PRS-X02).
